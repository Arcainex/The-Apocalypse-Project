# Last of Us Map Conversion

Static FiveM conversion of Den Edwin's two *Last Of Us* Menyoo map layouts.

- last_of_us_map1.ymap — 652 static props in South Los Santos.
- last_of_us_map2.ymap — 912 static props in Vinewood Hills.
- All mission-only entries, peds, vehicles, task sequences, ASI/DLL files and custom-prop dependencies are excluded.
- Placement rotations are preserved; converted props use a 500m LOD distance rather than the source map's unsafe 16,960m draw distance.

Original author: **Den Edwin** — [YouTube channel](https://www.youtube.com/channel/UClJBgAvRc-RQyjkjr6TT9WA)
