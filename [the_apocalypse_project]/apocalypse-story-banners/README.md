# Apocalypse Story Banners

Map-wide replacements for common property banners and city billboards.

The large fence banner carries evacuation and survivor warnings. The first city billboard family uses damaged framing, weathered materials and an abandoned emergency message while preserving the original drawable, collision bounds and streaming behavior.

Test after `refresh` and `ensure apocalypse-story-banners`. Reconnect before comparing enabled and disabled states because FiveM can retain streamed drawables in the client cache.
