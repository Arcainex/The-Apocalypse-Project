# Apocalypse Gas Stations

Map-wide texture replacements for fuel pumps, station buildings, canopies,
forecourts, roadside price signs and supporting equipment.

The package changes appearance only. It does not replace geometry, alter
collisions or add framework dependencies.

Original GTA texture dictionaries are mapped to the apocalypse texture shards
at runtime so embedded pump and building materials receive the same treatment.

## Coverage

- 67 station, pump, sign, forecourt and building texture dictionaries
- 356 active texture replacements
- 12 streamed shards, each below 10 MiB

Fuel pumps and metalwork receive heavy corrosion and grime. Forecourts,
sidewalks and station grounds receive stronger cracking and growth, while
branding remains recognisable beneath the decay.
