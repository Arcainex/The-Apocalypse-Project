# The Apocalypse Project

The Apocalypse Project aims to create the most immersive post-apocalyptic FREE map for FiveM.
Some of the maps inside are found on GTA V Mods and they were converted to YMAP.
The authors are credited down below.

Thanks to Savolent, we now have a fully working version of this project for communities to work. His Discord is listed down in the credits.

To ensure this project does not die and to prevent the community from getting lost between multiple forks, I decided to merge the most stable and updated community versions directly into the main project.

Because this is an open-source project, our goal is simple:
Keep everything unified, updated, and accessible in one place for everyone.

This merge includes improvements from:

- SparksScripts – Total Apocalypse
  https://github.com/SparksScripts/Total-Apocalypse

- SantosMods – Total Apocalypse Revisited
  https://github.com/SantosMods/Total-Apocalypse-Revisited/tree/main

Both projects contributed major fixes, optimizations, and expanded destruction zones.
Their work has now been merged into this repository to ensure the community always has access to the best and most up-to-date version.

I have also added several fixes of my own, including duplicated prop cleanup, performance improvements, and general stability fixes. These will be included in upcoming commits.

### Installation

The Apocalypse Project requires IPLs in order to be 100% functional.

Place the `[the_apocalypse_project]` folder in your server `resources` directory and add the following to `server.cfg`:

ensure [the_apocalypse_project]
