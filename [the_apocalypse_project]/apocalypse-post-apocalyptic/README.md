# Post Apocalyptic Airbase

Static FiveM conversion of the authorized *Post Apocalyptic Map* layout.

- Location: Grand Senora Desert, near Bolingbroke Penitentiary / the satellite dishes.
- Source format: Map Editor XML.
- Converted output: post_apocalyptic_airbase.ymap with 1,066 static, conflict-free placements.
- Runtime scripts, peds, vehicles, and other non-static content are excluded.
